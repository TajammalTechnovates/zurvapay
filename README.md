## 📌 What is ZurvaPay? — What does this project do?

ZurvaPay is a hosted payment gateway: a merchant sends one server-side request, the customer pays on ZurvaPay's secure hosted checkout with JazzCash, Easypaisa or Raast QR, and ZurvaPay instantly notifies the merchant's server with a signed IPN. Its hard security rule: a payment settles only inside signature-verified IPN handling — never from a success page — so fake payments can never credit an order.

## 🎯 Who is it for?

E-commerce stores, marketplaces, SaaS & digital products, freelancers, education, ticketing, wallet top-ups and service businesses in Pakistan — plus agencies (sub-merchants) and agents earning commission.

## ⭐ Key Features & Services — What it offers

- ✅ JazzCash, Easypaisa & Raast QR live today — Pakistani banks & cards in the same checkout
